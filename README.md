# Щогодинний сигнал

Chrome-розширення, яке рівно на початку кожної години (8:00, 9:00, ..., 23:00, 0:00) програє обраний звук — як сигнал наручного годинника Casio. Нагадування, щоб не забувати пити воду, вставати з-за компʼютера і відчувати, як минає час.

## Як це працює

- Кожну хвилину фонова служба (`background.js`) перевіряє поточний час через `chrome.alarms`.
- Якщо хвилина рівно `00` і сигнал ще не грав цієї години — програється звук.
- Оскільки service worker не має доступу до `Audio`, відтворення відбувається через прихований offscreen-документ (`offscreen.html`/`offscreen.js`).
- У popup (`popup.html`/`popup.js`) можна увімкнути/вимкнути сигнал, обрати один із 12 доданих звуків, налаштувати гучність і перевірити звук кнопкою.

## Структура

```
manifest.json      — конфігурація розширення (Manifest V3)
background.js       — service worker: таймер і логіка "чи вже рівно година"
offscreen.html/js   — прихована сторінка для відтворення звуку
popup.html/css/js   — інтерфейс налаштувань
icons/              — іконки розширення (16/32/48/128px)
sounds/             — набір звукових файлів на вибір
```

## Встановлення (режим розробника)

1. Відкрити `chrome://extensions`.
2. Увімкнути «Режим розробника».
3. Натиснути «Завантажити розпаковане» і обрати цю папку.

## Обмеження

Сигнал працює, поки Chrome відкритий (можна у фоні/згорнутий). Якщо браузер повністю закрито, сигнал того моменту не пролунає.
